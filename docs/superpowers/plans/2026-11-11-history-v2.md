# Jot 1.3 — Bibliothèque de dictées

Objectif : implémenter directement le cahier des charges utilisateur du 11 novembre 2026 sur `615d531`, dans `codex/history-v2`.

Architecture : dossiers de session sources, SQLite dérivé. `corrections.json` versionné garde chaque correction explicite (identifiant, avant, après, date). Le moteur conserve `meta.json` sans risque d'écraser ce fichier. FTS5 unicode61, accents ignorés, recherche par mots/préfixes; liste paginée à aperçus bornés; détail chargé séparément. Statistiques sur le texte affiché, mêmes formules 1.2, une session comptée une seule fois.

- [x] Stockage : migration additive, FTS et triggers, corrections atomiques avec contrôle de concurrence, suppression validant identité et dossiers, reprise existante. Tests de sauvegarde/rechargement, corruption, profils anciens, réindexation et notifications.
- [x] Éditeur : prolonger TextField pour multiligne sans modifier les champs simples; IME, Unicode, sélection, annulation et événement Changed. Tests dédiés.
- [x] Historique : requêtes en arrière-plan et saisie temporisée, filtres combinés, pagination, regroupement local, détail/édition/copie/originaux, suppression multiple confirmée, reprise et retours FR/EN. Protection du brouillon lors de navigation.
- [x] Intégration : tests fictifs, mesures distinctes 100/1k/10k/100k, fmt, clippy, tests workspace, Release Windows; vérification visuelle isolée si possible. Aucun historique personnel ni appel Gemini pour les tests.
- [x] Livraison : version 1.3.0, portable `test-build/codex-history` avec marqueur, licences et notice; commit local, aucun push.

Points de revue : correction concurrente, sidecar corrompu, dossier remplacé/lien symbolique, reprise pendant suppression, résultats asynchrones périmés, changement de jour DST, brouillon non sauvegardé, volume/texte long. Pas d'apprentissage automatique ni surveillance clavier. Mécanismes HUD/Win32/capture/transcription conservés ; seule une condition imbriquée du wrapper HUD a été reformulée pour Clippy, sans changer les appels.
